# UnpaidUI

Open-source premium landing page templates made 100% free for everyone.
High-converting, production-ready landing page templates engineered with Next.js, Tailwind CSS, and modern UI libraries.

| Template | Directory | Description |
| --- | --- | --- |
| **TLDR** | `unpaidui/tldr` | AI summarization platform landing page |
| **SkyAgent** | `unpaidui/skyagent` | Autonomous AI agent platform landing page |
| **Kora** | `unpaidui/kora` | Growth consulting and advisory landing page |
| **Lumen** | `unpaidui/lumen` | Dark-mode WebGL shaders landing page |
| **MindScript** | `unpaidui/mindscript` | Mindfulness and journaling platform |
| **Wellnest** | `unpaidui/wellnest` | Mental wellness and therapy landing page |

| **ImageWorks** | `unpaidui/imageworks` | Creative visual production studio |

## Run locally

Each template in `unpaidui/` is an independent Next.js project.

Requires **Node.js 20+** and **pnpm** (or npm/yarn).

```bash
cd unpaidui/tldr # or choose another template
pnpm install
pnpm dev
```

For production builds:
```bash
pnpm build
pnpm start
```
